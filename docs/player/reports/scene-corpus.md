## A/B against the legacy engine (`--ab-legacy`)

Not run yet — it takes over the desktop session (the installed `linux-wallpaperengine` draws
each scene on a real output for ~20 s), so the owner runs it:

```sh
livepaper --kill   # stop the app's own wallpaper first
bash src/player/tests/onmachine/scene_corpus.sh --ab-legacy --legacy-output DP-1 \
     --reuse /tmp/lp-scene-corpus-<stamp>   # reuse this run's lp-player half (or omit to redo it)
```

It screenshots each scene with LWE's own `--screenshot` (`--screenshot-delay 120` frames),
classifies a screenshot that isn't blank as "starts", rewrites this report with the lists
below, and kills each LWE it started. Until then **every non-ok scene above counts as
possibly newly failing** and has a Phase 6 entry in `docs/TODO.md` (§11.5 acceptance).
